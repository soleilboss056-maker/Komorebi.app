# 🌿 Komorebi.app

**Komorebi.app** is a modern web application developed with Next.js and React.

> *Komorebi (木漏れ日)*: the Japanese word for sunlight filtering through tree leaves.

---

## 🚀 Features

- ⚡ **Optimal performance** thanks to Next.js (App Router)
- 🎨 **Modern & responsive interface**
- 🛠️ **Clean architecture** and easy to scale

---

## 🛠️ Technical Stack

- **Framework:** [Next.js](https://nextjs.org) (React)
- **Styling:** Tailwind CSS
- **Language:** TypeScript / JavaScript
